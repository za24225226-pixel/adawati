# أدواتي | Adawati — نسخة البداية

## التشغيل
1. ثبّت Node.js (إصدار حديث).
2. افتح مجلد `adawati` في VS Code.
3. افتح Terminal داخل المجلد وشغّل:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى ملف جديد اسمه `.env` وضع مفتاح OpenAI API الخاص بك داخله.
5. شغّل:
   ```bash
   npm start
   ```
6. افتح `http://localhost:3000`.

## الموجود في النسخة
- واجهة عربية RTL قابلة للتبديل إلى الإنجليزية.
- وضع فاتح/داكن وقائمة جانبية متجاوبة.
- صفحة Zoz AI متصلة بمسار خلفي يحفظ مفتاح API على السيرفر.
- بطاقات CV والسعرات والأقساط والألعاب، مع نماذج أولية لبعض الوظائف.
- صفحة الأدوات والمفضلة ورابط الدعم.

## مهم قبل النشر
هذه نسخة أولية وليست جاهزة للإطلاق العام بعد:
- تسجيل الدخول الحالي غير منفّذ؛ زر الخروج يوضح ذلك. يلزم ربط Firebase Auth أو مزود مصادقة آمن.
- أضف حماية من إساءة الاستخدام وحدودًا للطلبات وتحققًا من المدخلات ومراقبة للتكلفة على مسار Zoz AI.
- أدوات CV وتصدير PDF وأدوات الملفات والألعاب الموسعة تحتاج استكمالًا.
- لا ترفع ملف `.env` أو مفتاح API إلى GitHub ولا تضع المفتاح في ملفات `public`.
- تقدير السعرات عام وليس نصيحة طبية.
